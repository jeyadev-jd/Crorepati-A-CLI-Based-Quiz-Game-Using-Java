# Crorepati: A CLI-Based Quiz Game Using Java

This project involves the development of a CLI-based quiz game using Java, inspired by "Who Wants to Be a Millionaire" (Crorepati). The application runs in the command-line environment and allows users to answer multiple-choice questions through keyboard input. The questions and options are stored using structured data, and the program evaluates user responses to calculate the score. A basic timing check is used to measure how quickly the user answers each question, and a simple 50-50 lifeline option is provided to remove incorrect choices once during the game.

## Features
- Multiple-choice questions
- Timed answers
- 50-50 Lifeline
- Immediate feedback and scoring

